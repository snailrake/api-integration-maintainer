# API Maintainer · frontend

Экран входа и интерактивная демонстрация адаптации клиента к изменению API.

Для запуска подойдёт Node.js 22.12 или новее. Выполните в каталоге frontend.

~~~sh
npm ci
npm run dev
~~~

Для сборки используйте npm run build. Форма входа работает в демонстрационном режиме.
